# Script or code request

**Use:** You need a script written, fixed, or changed.

```
[What the script should do, start to finish]

Environment: [OS, language and version, admin rights yes/no, paths, share names]

What I have / the error: [Paste the current script or the exact error text]

Done looks like: [e.g. "Complete script, comments on each section, steps to schedule it"]

How to answer: Give me one answer, your best pick. Give me the complete script, not fragments.
```

## Example

```
PowerShell script that copies D:\Projects to my NAS every night and keeps the last 7 days of copies.

Environment: Windows 11, PowerShell 5.1, no admin rights. NAS share is \\nas\backup. Log to C:\Logs.

What I have / the error: Last attempt failed with: Access to the path '\\nas\backup' is denied.

Done looks like: Complete script, comments on each section, and steps to schedule it in Task Scheduler.

How to answer: Give me one answer, your best pick. Keep it short.
```
