# Quick question

**Use:** You want an explanation, a fact, or a comparison.

```
[Your question in one sentence]

Context: [What you already know or have tried]

Done looks like: [Format and depth, e.g. "plain-English explanation plus one real example"]

How to answer: [Give me one answer, your best pick. | Give me 2–3 options with the tradeoffs, then say which you'd pick.] [Keep it short. | Be thorough; detail is fine.]
```

## Example

```
What's the difference between a VLAN and a subnet, and do I need both on my home network?

Context: Solid on basic networking. I'm setting up a managed switch and want IoT devices separated from my main PCs.

Done looks like: Plain-English explanation, one example from a home setup, and whether I actually need both.

How to answer: Give me one answer, your best pick. Keep it short.
```
