# Work / NetSuite task

**Use:** Admin tasks, reports, saved searches, user requests, work emails. Keep real names and internal details out of this public repo.

```
[The problem or task: what needs to exist or be fixed]

System/access: [e.g. "NetSuite, admin role, no SuiteScript, limited SuiteQL"]

Audience: [Who uses the result and how they'll get it]

Done looks like: [e.g. "Exact criteria and columns, click-by-click in the UI"]

How to answer: [Give me one answer. | Show me the plan first and wait for my go-ahead.] [Keep it short. | Be thorough.]
```

## Example

```
I need a saved search of open sales orders older than 30 days, grouped by customer.

System/access: NetSuite, admin role, no SuiteScript, limited SuiteQL.

Audience: Sales manager. She'll get it as a scheduled email every Monday.

Done looks like: Exact criteria and result columns, click-by-click in the UI, plus how to schedule the email.

How to answer: Give me one answer, your best pick. Keep it short.
```
